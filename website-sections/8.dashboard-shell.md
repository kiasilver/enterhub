# 8. Dashboard Shell — Specs

## Content
- Entry: `/dashboard` → `SafeDashboard`
- Brand in sidebar: **ENTERHUB**
- Default page: Project Overview (`dashboard` id)
- Customizer: theme, primary color, background style (plasma/mesh/dots/grid/aurora/solid)

## Layout Reference
- `frontend/src/app/dashboard/page.tsx`
- `frontend/src/components/SafeDashboard/SafeDashboard.tsx`
- Shell: `SafeSidebar` + `SafeTopbar` + active page module

## Components to Use
**Always compose from ELEMENT_CATALOG section D–E.**

Priority modules for a PM product:
1. `SafeStatsRow` / overview widgets in `SafeDashboard`
2. `SafeProjects`, `SafeTasks`
3. `SafeCalendar` (+ mobile)
4. `SafeChat` (+ mobile)
5. `SafeTeam` / `SafeTeamPage`
6. `SafeSettings` / account shell
7. `SafeRecharts` for analytics

Demo-only (keep code, optionally hide in nav): NFT, Crypto, Ecommerce, Job board demos.

## Theme / glass
- Panels: `glassStyle(isDark)` from `theme.ts`
- Sidebar/topbar: `glassSidebar` / `glassTopbar`
- Background: respect `ThemeProvider.bgStyle`

## Design Instructions
- Never rebuild sidebar from scratch
- Nav label edits go in `SafeSidebar.tsx` NAV config
- Mobile: use existing drawer/open sidebar props + `*Mobile` pages
- Charts: Recharts modules already themed — pass `isDark`
