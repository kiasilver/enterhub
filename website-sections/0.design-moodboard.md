# Design Moodboard — ENTERHUB (from Coreinet/dashboard)

> This is the **general vibe** for the whole site. Implementation lives in `frontend/`.  
> Do not introduce a second aesthetic (no purple-gradient SaaS clichés, no new card systems).

## Inspiration References

### Reference 1: Coreinet Dashboard (primary — already in repo)
- URL: https://github.com/Coreinet/dashboard
- Local: `frontend/src/`
- What we keep:
  - Full-bleed **Plasma** WebGL background
  - **Glass** navbar / auth cards / dashboard panels
  - Pill CTAs (inverted black/white by theme)
  - Variable-font proximity headline (`VariableProximity` + Roboto Flex)
  - In-app **SafeDashboard** module gallery (charts, tables, apps, settings)

### Reference 2: ENTERHUB brand overlay
- Product name replaces Safe / SafeGuard in user-facing copy
- Component folder names may still say `Safe*` — that is OK; do not mass-rename unless asked

## Aesthetic Keywords
Dark-first, premium SaaS, glassmorphism, plasma / fluid energy, minimal chrome, technical calm, high contrast CTAs, soft blur edges

## Colors

| Token | Dark | Light | Notes |
|-------|------|-------|--------|
| Background | `#000000` | `#ffffff` / `#f0eded` | Marketing uses pure black/white; CSS vars use `#f0eded` light |
| Foreground | `#ffffff` | `#0a0a0a` | |
| Primary accent | `#6366f1` (Indigo) | `#4f46e5` | Live via `ThemeProvider.primaryColor` → CSS `--primary` |
| Glass fill | `rgba(15,15,17,0.96)` cards / `0.5` nav | `rgba(255,255,255,0.92)` | See `SafeDashboard/theme.ts` → `glassStyle` |
| Glass border | `rgba(255,255,255,0.08)` | `rgba(0,0,0,0.08)` | |
| Muted text | `rgba(255,255,255,0.55–0.6)` | `rgba(0,0,0,0.5–0.6)` | |
| Plasma tint | `#9d9696` | `#6b6060` | `PlasmaWrapper` |

**Accent rule:** Primary indigo is for highlights, charts, active nav, rings — **not** for large text blocks. Primary CTA on marketing is inverted (white on dark / black on light).

## Typography
| Role | Font | Source |
|------|------|--------|
| UI / body | Geist Sans | `layout.tsx` → `--font-geist-sans` |
| Mono | Geist Mono | `--font-geist-mono` |
| Hero variable | Roboto Flex (`opsz`, `wdth`) | `VariableProximity` |
| Marketing Inter | Inter (weights 400–800) | available CSS var |
| Icons | Lucide, Remix Icon, Heroicons, Boxicons, Material Icons, react-icons | Already installed — prefer what a given Safe* module already uses |

## Effects & Textures
1. **Plasma** — OGL WebGL fullscreen (`components/Plasma`)
2. **Glass** — `backdrop-filter: blur(12–18px)`, rounded `16–32px`
3. **BorderGlow** — optional accent outline component
4. **Motion** — `motion/react` for navbar mobile drawer & micro-interactions
5. **GSAP / Lottie / Lordicon** — used inside dashboard icon/animation demos
6. Background styles (dashboard customizer): `plasma | solid | mesh | dots | grid | aurora`

## Layout Feel
- Marketing: one composition per viewport; hero = brand + headline + one supporting line + CTA pair + plasma
- Dashboard: glass sidebar + topbar over plasma; content in `glassStyle` cards
- Radius: pills (`rounded-full`) for nav CTAs; `rounded-2xl` / `rounded-[24px]` / `rounded-[32px]` for panels

## Non-goals
- No FastAPI / Postgres / Redis in this repo
- No second shadcn redesign that fights Coreinet tokens
- Do not replace Plasma with flat solid backgrounds as the default marketing look
