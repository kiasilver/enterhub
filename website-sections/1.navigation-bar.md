# 1. Navigation Bar — Specs

## Content
- Brand: **ENTERHUB** (logo mark + wordmark)
- Links: About · Privacy & Security · Contact
- CTAs: Sign In → `/signin` · Get Started / Dashboard → `/dashboard` or `/signup`
- Control: ThemeToggle (dark/light)

## Layout Reference
- Implementation: `frontend/src/components/Navbar/Navbar.tsx`
- Upstream: Coreinet/dashboard Navbar

## Components to Use
### Navbar (existing)
- Source: GitHub / local `Navbar/Navbar.tsx`
- Description: Fixed top bar, glass fill, backdrop blur, bottom border
- Behavior: Desktop centered links; mobile full-screen drawer via `motion` AnimatePresence

### ThemeToggle
- Source: `ThemeToggle/`

## Design Instructions
- Glass: dark `rgba(15,15,17,0.5)` / light `rgba(255,255,255,0.6)`
- Border bottom: white/black at ~10% opacity
- Do **not** wrap nav links in a pill container (current Coreinet pattern: text links)
- Keep seamless with hero (no hard opaque band)
- Always sit above Plasma (`z-50`) with content `z-10`

## Animations / Effects
- Mobile menu: Motion enter/exit
- Theme colors: `transition-colors duration-300`
