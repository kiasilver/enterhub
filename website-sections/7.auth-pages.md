# 7. Auth Pages — Specs

## Content
### Sign In (`/signin`)
- Title: Welcome back
- Sub: Sign in to your ENTERHUB dashboard
- Fields: Email, Password
- Primary: Sign In
- Link: Sign up → `/signup`
- Mode: **Demo local session** (no backend) — any email/password stores localStorage and routes to `/dashboard`

### Sign Up (`/signup`)
- Title: Create an account
- Sub: Join ENTERHUB…
- Fields: Full name, Company, Email, Password (as implemented)
- Link back to Sign In

### Alias
- `/login` redirects to `/signin`

## Layout Reference
- `frontend/src/app/signin/page.tsx`, `signup/page.tsx`
- Centered glass card over Plasma + Navbar

## Components to Use
- `PlasmaWrapper`, `Navbar`
- Auth card pattern: `rounded-[32px] backdrop-blur-2xl`
- Inputs: `rounded-2xl` transparent with theme border
- Submit: full-width inverted pill/rounded-2xl button
- Optional templates: `SafeDashboard/SafeAuth.tsx` for additional auth layouts inside dashboard

## Design Instructions
- Do not add OAuth until a real auth provider exists
- Keep validation minimal but required fields enforced
- Preserve Coreinet glass aesthetic exactly
